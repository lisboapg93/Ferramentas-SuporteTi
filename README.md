# Painel de Suporte TI

Painel em PowerShell para o suporte do dia a dia nas máquinas Windows: limpeza de temporários, fila de impressão, cache do Teams, diagnóstico de hardware e outras rotinas. Registra tudo o que foi feito em um log.

Para abrir, dê dois cliques em `Abrir Painel TI.bat` (pede permissão de administrador).
